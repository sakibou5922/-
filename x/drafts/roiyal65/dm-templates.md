# @ROIYAL65 DMの型（/x-dm）

## 仕分け
| 種類 | 対応 |
|---|---|
| 制作の相談 | 下の「最初の返事」 |
| 雑談・応援 | 短くお礼だけ |
| 「簡単に稼げる」「先にお金を」「外部アプリへ」「個人情報を」 | **返さない・リンクを開かない** |
| 他社の営業 | 興味がなければ返さなくてよい |

今のサイトがあれば、URLも教えてもらえると話が早いです。
```

```
※ 料金の目安が決まったら `x/accounts/roiyal65.md` の「収益化」欄に書き、ここも差し替える

## 守ること
- 一斉送信・同じ文面のコピペ連投・自動送信はしない
- 自分から知らない人へ売り込みDMは送らない（相談が来た人にだけ返す）
- 契約内容（作るもの・金額・納期・支払い方法）は、作業を始める前にメッセージで残す
- 前払いを求める相手、外部アプリに誘導する相手は警戒する
