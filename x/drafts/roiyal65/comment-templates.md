# @ROIYAL65 リプ・引用の型（/x-comment）

貼り付けるだけで使えるように、話題ごとに2つずつ。**同じ文をあちこちに貼らない**（スパム扱いになる）。相手の言葉を1つ拾って言い換える。

## 絡む前のチェック
- [ ] 政治・宗教・個人攻撃・炎上中ではない
- [ ] 投稿から2時間以内・返信50件未満
- [ ] 相手を否定せず、乗っかって自虐で落とせる
