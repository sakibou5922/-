# アカウント一覧（全 /x-* スキルが最初に読む）

運用中のアカウントごとに `x/accounts/<ハンドル小文字>.md` がある。

1. 依頼文にハンドル（@◯◯）があればそのファイルを使う
2. なければ下の「メイン」を使う。どちらか曖昧なら1問だけ確認する
3. 新しいアカウントが出てきたら、既存ファイルをひな形に `x/accounts/<ハンドル>.md` を作り、この一覧に追記する
4. 下書き・スワイプ・分析は `x/drafts/<ハンドル>/` のようにアカウント別に保存する
