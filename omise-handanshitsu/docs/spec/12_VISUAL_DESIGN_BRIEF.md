# 12｜Visual Design Brief Candidate

## Design Goal
「比較サイト」「ASPサイト」「SaaSダッシュボード」に見せない。
小規模店舗の経営者が、少し立ち止まって判断できるEditorial / Decision Utilityとして見せる。

## Tone
- 親しみはあるが幼くしない
- 専門家然としすぎない
- 営業感を抑える
- 結論は明確
- 不安を煽る赤警告だらけにしない

## Visual Direction
- Base: warm off-white / paper-like neutral
- Main: deep charcoal or dark green/navy
- Action accent: restrained warm orange/coral
- Success/Now/Next/Not-neededは色だけでなくlabel/icon/headingで識別
- 余白大きめ、表よりDecision Card中心
- 日本語見出しを大きく、本文は読みやすい行長

## Home Hero
Left: H1 + body + CTA
Right: 3段Decision visual
`今整える / 次に考える / 今はいらない`
商品ロゴをHeroに並べない。

## Article Page
1. Search question
2. Immediate Answer box
3. Why people use it
4. Cost / burden facts
5. Decision table
6. Mini Check
7. Result card
8. Alternative when not needed
9. Next action
10. Offer cards only after need confirmation

## Core Check
- 1 question / screen
- progress indicator
- card selection
- back/edit answers
- no affiliate during questions
- result page emphasizes reasons, not score

## Result Page
Primary visual hierarchy:
1. 無料で先に整える
2. 今、整える（max3）
3. 次に考える（max2）
4. 今は優先しない
5. 既存サービスの見直し

Offer cards are visually lower than decision cards.

## Mobile
- single-column
- sticky CTA only for core check entry; no sticky affiliate CTA
- comparison tables reflow into cards
- 44px-class touch targets
- long brand/service names wrap safely

## Avoid
- generic gradients / glassmorphism / neon AI aesthetic
- gold ranking medals
- No.1/No.2 ranking cards
- excessive red warning blocks
- stock-photo-heavy hero
- dashboard-like KPI cards on every page
- fake reviews / fake testimonials
- generated screenshots containing unreadable text

## Visual Source Priority
1. Actual HTML/SVG diagrams
2. Simple icons
3. Authentic/licensed photos if needed
4. Generated imagery only when text/UI is not baked into image

## Design Deliverables Before Implementation
- Home PC/SP
- Core Check question PC/SP
- Core Check result PC/SP
- 5 article template PC/SP
- Mini Check state
- Offer card state
- stale fact / offer unavailable state
- 404
