`Question → Immediate Answer → Why used → Fit → Cost → Risk/Dependency → Mini Check → Individual Result → Alternative → Next Action → Offer if needed`

- indexable text
- unique title/description/canonical
- internal links
- visible review date
- Article/Breadcrumb/Organization structured data where applicable

- no special AI-search hack
