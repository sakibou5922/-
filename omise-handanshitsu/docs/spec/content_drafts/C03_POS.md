# POSレジは本当に必要？小さなお店で入れる店・まだ不要な店

## 結論
POSは「店を開くなら必要な高性能レジ」ではありません。在庫、商品数、スタッフ、売上分析、決済・会計連携が複雑になったときに価値が出ます。

## 1人・在庫なしなら？
メニューが少なく、在庫管理が不要で、1人運営なら高度なPOS機能の優先度は低い場合があります。

## ただし無料POSという選択もある
Square POSレジアプリは現在無料で、決済端末は別費用です。Airレジもアプリ・月額・基本サポート0円で、必要な周辺機器は別途です。`SRC-SQUARE-POS`, `SRC-AIRREGI`

つまり「POSを導入するか」と「高額なPOSを契約するか」は別の判断です。

## POS価値が高くなる条件
- 在庫が重要
- 商品/メニューが多い
- 複数スタッフ
- 担当別/商品別売上を見たい
- キャッシュレスや会計と連携したい

## 判断
SIMPLE_REGISTER_OK / FREE_POS_FIT / ADVANCED_POS_FIT / INTEGRATION_REVIEW

## 比較方針
Squareだけを出しません。Affiliate対象でなくてもAirレジ等の公式選択肢を出し、適合条件で比較します。

## 導入後に測る
締め作業時間、在庫差異、集計時間、転記数、売上分析の利用頻度。
