# キャッシュレス決済は本当に必要？手数料を払う価値がある店・ない店

## 結論
「今どき必須」だけでも「手数料がもったいない」だけでも決めません。客層、店頭決済の多さ、客単価、粗利、現金管理負荷から判断します。

## 月の実コストを計算
`キャッシュレス売上 × 決済手数料率 + 月額固定費`

例えば料率だけ見ても、提供会社・ブランド・審査・Program条件で異なるため、最新の自店適用条件を使います。

Squareは現行でPOS app無料、決済料率は条件により2.5%〜の案内があります。Airペイは初期・使用・月額・振込手数料0円の案内があり、別途決済手数料が発生します。`SRC-SQUARE-POS`, `SRC-AIRPAY`

## 導入価値が高い店
- 店頭決済が多い
- 顧客からカード/QR要望がある
- 客単価が高め
- 現金管理の負荷が大きい

## 優先度が低い店
- 店頭決済がほぼない
- 請求書/振込中心
- 現状の支払手段で顧客不便が確認できない

## 判断
HIGH_FIT / CONDITIONAL / LOW_PRIORITY

## 比較
必要性が確定したあとだけ、Square等のAffiliate候補とAirペイ等の公式候補を比較します。

## 導入後に測る
キャッシュレス利用率、月間手数料、会計時間、現金締め時間、顧客要望。
