# LINE公式アカウントは本当に必要？小さなお店が作る前に考えたいこと

## 結論
無料だから作るのではなく、再来、通知、予約導線など明確な用途があるなら作る。開業前で顧客がほぼいない状態では、新規集客や営業準備より先にすべきとは限りません。

## LINEが得意なこと
既に接点のある顧客との継続接点を作りやすいことです。新規集客媒体と再来施策を混同しません。

## 現行料金
LINE公式アカウントは、コミュニケーション0円/200通、ライト5,000円税別/5,000通、スタンダード15,000円税別/30,000通の現行案内です。2026-10-01には追加メッセージ料金改定もあります。`SRC-LINE-PLAN`

## 無料で足りるかを先に見る
`友だち数 × 月配信回数` から必要通数を概算します。

ただし、配信できるから価値があるわけではありません。何を送り、どのActionにつなげるかを先に決めます。

## 判断
START_FREE / USE_WITH_PURPOSE / SCALE_AFTER_VALUE / NOT_PRIORITY

## 予約との関係
LINEを予約窓口にしたい場合、予約システムと組み合わせる選択肢もあります。LINEを作っただけで予約管理問題が解決するとは限りません。

## 導入後に測る
友だち純増、配信到達、ブロック、予約/再来Action、配信コスト。
