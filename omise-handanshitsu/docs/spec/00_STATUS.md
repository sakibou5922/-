## Purpose
小規模店舗・対面サービス事業者が、予約、POS、キャッシュレス、LINE、外部集客媒体、会計、Web等について、`本当に必要か / 今必要か / 何番目か / 導入後に何を測るか` を判断できるようにする。

主収益はASP / Partner Program。SMASKは既製サービスだけで解決しにくい場合のSecondary Exit。

## Hard Principle
`Problem → Understand → Individualize → Decide → Act → Offer if needed`

禁止: Affiliate報酬でNeed判定を変える、全員にSMASK相談、企業批判を価値の代わりにする、診断を絶対判定として表示する。

## Usefulness Gate
1. 読む前より良い判断ができる
2. 必要/条件付き/まだ不要の基準が具体的
3. 不要時の代替がある
4. 必要時の次Actionが明確
5. Affiliateを全削除しても価値が残る

5がNOなら公開しない。
