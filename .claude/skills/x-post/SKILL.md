# /x-post — アイデア → 投稿

## 手順
1. `x/account.md` と `x/playbook.md` と `x/hooks.md` を読む。`x/account.md` のジャンル・届けたい相手・口調が空欄なら、先に質問して埋める（ファイルも更新）。
2. アイデア（$ARGUMENTS）が曖昧なら1問だけ確認する：「この投稿で起こしたい行動は？（保存 / 返信 / フォロー / 商品への興味）」
3. `x/swipe/` に記録があれば、伸びた型を優先候補にする。
4. 21種から相性の良い型を **5つ** 選び、それぞれ1行目（フック）を作る。
5. 各フックを `x/hooks.md` の5軸（各20点）で採点し、表で出す：

   | # | 型 | 1行目 | 停止 | 適合 | 好奇心 | 信頼 | 行動 | 計 |

6. 上位2案を本文まで完成させる。構成は「1行目フック → 空行 → 中身（箇条書き or 3〜5行）→ 締め（問いかけ・保存促し・プロフィール誘導のどれか1つ）」。
7. 完成案を必ず `python3 x/scripts/x_count.py "本文"` で数え、結果をそのまま見せる。280を超えたら削る（Premium加入済みで長文を選ぶ場合のみ超過可）。
8. 最後に `/x-human` の観点（AIっぽい表現）で自己チェックしてから出す。

## 出力
- スコア表
- 完成案 A / B（文字数チェック結果つき）
- おすすめの投稿時間帯と、投稿直後にやること（返信欄に置く補足・リンクなど）
- ユーザーが選んだ案は `x/drafts/YYYY-MM-DD-post.md` に保存

## 守ること
- 本文に外部リンクを入れない（返信欄に置く提案をする）
- 誇大な収益表現・根拠のない数字を作らない。数字はユーザーの実体験か、仮置きなら `【要確認】` と明記
- ハッシュタグは0〜1個
