# /x-engage — コメント・返信・DM・再利用

最初に `x/account.md` で口調・ジャンル・商品を確認する。依頼内容から下のどれかを選ぶ。

## A. 他人の投稿へのコメント案（伸びている同ジャンル投稿に早めに付けるのが一番の集客）
- 3案出す：①具体的な体験の上乗せ ②別の視点・補足 ③短い共感＋質問
- 「すごい！」「勉強になります」だけのコメントは出さない。自分のプロフィールを見たくなる一言を入れる
- 宣伝・リンクは入れない。各案を `python3 x/scripts/x_count.py` で確認

## B. 自分の投稿への返信対応
- 返信は全部に返すつもりで（投稿者の返信は評価が重い）。質問には答え＋逆質問で会話を続ける
- 批判・揚げ足取りには、事実の訂正が必要なら1回だけ丁寧に。感情的な相手には返さない選択肢も示す
- 炎上の兆候（引用で批判が連鎖）があれば、謝罪・補足・静観のどれが良いか理由つきで提案

## C. DM
- 受信DMへの返信：相手の悩みを1つ確認する質問 → 解決策の一部を無料で → 必要なら商品・面談を「提案」（押し売りしない）
- 自分から送るDM：一斉送信・テンプレ感はスパム判定のリスク。相手の投稿を具体的に1つ挙げ、要件を短く、断りやすく
- 金銭・個人情報のやり取りは公式の決済・フォームへ誘導する

## D. 再利用（伸びた投稿は形を変えて何度でも使う）
- 伸びた単発 → 1〜2週間後に別のフック型で言い換え（`x/hooks.md`）
- 単発を複数束ねる → スレッド or 長文（`/x-thread`）
- スレッド → note（無料/有料）・LINE配信・Instagramカルーセル・Threads 向けに要約
- 再利用案は `x/drafts/` に保存する
