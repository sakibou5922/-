# /x-thread — スレッド・長文・単発の判断と組み立て

## 1. 形式の判断（理由を一言添えて決める）
| 条件 | 形式 |
|------|------|
| 言いたいことが1つ・140字で言える | 単発（`/x-post` の手順で作る） |
| ノウハウが3〜7個・手順・リスト | スレッド（各ポスト1論点） |
| ストーリー・深い解説で途中で切りたくない・Premium加入済み | 長文投稿 |
| Premium未加入で長い内容 | スレッド |

## 2. スレッドの型
1. **1本目**: フック（`x/hooks.md` から2〜3案を採点して最高点を採用）＋「このスレッドで分かること」＋「🧵」か「↓」
2. **2本目〜**: 1ポスト1論点。各ポストの1行目も小見出しとして強くする。番号（1/ 2/ …）を振る
3. **最後から2本目**: まとめ（保存したくなる要約）
4. **最後**: 行動の呼びかけ（フォロー / プロフィールのnote・LINE誘導 / 返信で質問募集）。外部リンクはここに置く
- 目安は5〜8本。10本を超えるなら分けるか長文にする

## 3. 長文投稿の型
- 冒頭の数行（タイムラインに出る部分）だけで続きを読みたくなるように書く
- 見出し・空行・箇条書きで読みやすく。結論は早めに
- 最後に要約とアクション

## 4. 検証
- 下書きを `x/drafts/YYYY-MM-DD-thread.md` に、ポスト間を `---` 行で区切って保存
- `python3 x/scripts/x_count.py -f x/drafts/YYYY-MM-DD-thread.md --split` で全ポストを検証し、結果を見せる。超過したポストは直す
- 仕上げに `/x-human` の観点でAIっぽさを除く
