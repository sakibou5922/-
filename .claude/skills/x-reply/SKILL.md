# /x-reply — 自分のポストへの返信対応

## 手順
1. `x/account.md` から対象アカウントのファイルを読み、口調・書かないことを確認する。
2. 付いたリプライを次の箱に仕分ける：
   | 箱 | 例 | 対応 |
   |---|---|---|
   | ① 質問 | 「何のAI使ってる？」 | 最優先で答える＋逆質問で会話を続ける |
   | ② 共感・応援 | 「わかる」「がんばれ」 | 短くキャラ口調で返す |
   | ③ 仕事の気配 | 「依頼できる？」「何ができるの？」 | 公開の場では短く返し、DMへ（`/x-dm`） |
   | ④ ツッコミ・ネタ | 「ネタでしょ」 | ネタで軽く返す |
   | ⑤ 批判・説教 | 「辞めればいい」 | 事実の訂正が要るときだけ1回丁寧に。感情的なら返さない |
   | ⑥ スパム・荒らし | 宣伝・誹謗 | 返さない。ひどければミュート・ブロック |
3. 返す順番：① → ③ → ② → ④ → ⑤（投稿後30分以内に①②を返すと伸びやすい）
4. 返信案を作り `python3 x/scripts/x_count.py` で数える。

## 守ること
- 本人が言っていない事実を足さない（数字・経緯は対象アカウントのファイルにあるものだけ）
- 進行中の交渉や法的な話（相談先・請求など）は、本人が「書いてよい」と言うまで一切触れない
- 炎上の兆候（引用で批判が連鎖）があれば、謝罪・補足・静観のどれが良いか理由つきで提案する
