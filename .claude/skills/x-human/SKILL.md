# /x-human — AIっぽさを消す

`x/account.md` の口調・一人称に合わせる。

## AIっぽさのチェックリスト（見つけたら直す）
- **決まり文句**: 「〜ではないでしょうか」「いかがでしたか」「重要なのは〜です」「〜することが大切です」「さあ、〜しましょう」「結論から言うと」の多用
- **大げさな語**: 「革命的」「圧倒的」「究極の」「完全ガイド」「徹底解説」「ゲームチェンジャー」
- **整いすぎた構造**: 毎回きっちり3つの箇条書き、全行が同じ長さ、すべての文が「。」で終わる
- **記号の癖**: 「：」「——」の多用、絵文字を各行の頭に並べる、【】の乱用、太字っぽい強調
- **抽象的**: 体験・固有名詞・数字・場面がない。「多くの人が」「様々な」
- **締めの定型**: 「参考になれば嬉しいです！」「ぜひ試してみてください！」で毎回終わる
- **敬語のブレ・硬さ**: タメ口アカウントなのに説明調になっている

## 直し方
1. 具体化：いつ・どこで・何円・何分・誰に言われた、を1つ入れる（ユーザーの実体験がなければ `【体験を入れる】` と空欄で残す。作り話はしない）
2. リズム：短い文と長い文を混ぜる。体言止め・言いさし・「笑」「正直」など口語を適量
3. 本音：迷い・失敗・感情を一言入れる
4. 削る：なくても意味が通る前置き・まとめを消す

## 出力
- 修正前後の比較（変えた箇所に理由を一言）
- 修正後の文字数（`python3 x/scripts/x_count.py "本文"`）
- AIっぽさスコア：修正前 ◯/10 → 修正後 ◯/10（10が最も人間らしい）
