# /x-monetize — 収益化の設計

## 手順
1. `x/account.md` から対象アカウントのファイルを選んで読み、空欄（ジャンル・相手・実績・目標・商品・時間）を質問で埋めてファイルを更新する。ジャンルが決まっていなければ、ユーザーの経験・好き・お金を払う人がいるか、の3つが重なるところを3案出して選んでもらう。
2. フォロワー規模に合う収益源を選ぶ（目安）：
   | 段階 | 主な収益源 |
   |------|------------|
   | 〜1,000人 | 個別相談・代行・コンサル（少人数でも単価で稼げる）、ココナラ等の出品、ジャンルに合うアフィリエイト |
   | 1,000〜5,000人 | 有料note・Brain・Tips などのデジタル商品、LINE公式での個別販売 |
   | 5,000人〜 | 講座・コミュニティ・企業案件（PR投稿）、X のサブスクリプション |
   | 認証済みフォロワー500人＋認証ユーザーからの表示50万/90日 | **インプレッション収益（Original Content Rewards）**。条件と禁止事項は `x/playbook.md` の「インプレッション収益」節。商品販売と並行して狙う |

   「インプで稼ぎたい」と言われたら：`x/playbook.md` の条件に対する現在地（認証済みフォロワー数・直近90日の表示回数）を聞き、条件達成までの日割り目標（例: 50万 ÷ 90日 ≒ 1日5,600表示）を出す。報酬単価は公表されておらず変動するので金額は約束しない。インプ収益は単価が低く不安定なため、商品導線（下の手順3）も必ず一緒に設計する。
3. 導線を1本に絞って設計する：
   **投稿 → プロフィール → 固定ポスト/リンク → 無料特典（チェックリスト・テンプレ等）→ LINE公式/メルマガ → 個別相談 or 商品**
4. 数値目標を逆算する（Pythonで計算して見せる）：
   月の目標額 ÷ 単価 ＝ 必要成約数 → ÷ 成約率（目安 個別相談10〜30%）→ 必要な見込み客数 → ÷ 登録率（プロフィール訪問の1〜5%）→ 必要なプロフィール訪問数 → 必要な表示回数
5. 最初の商品の中身案（タイトル・対象・中身の目次・価格・特典）と、無料特典の案を出す。
6. 30日のロードマップ：1週目 プロフィール整備（`/x-profile`）と無料特典づくり / 2週目 毎日投稿（`/x-plan`）＋コメント回り（`/x-engage`）/ 3週目 固定ポストで特典配布開始 / 4週目 振り返り（`/x-audit`）と商品の案内
7. `x/drafts/YYYY-MM-DD-monetize.md` に保存する。

## 守ること
- 根拠のない「月◯万円確実」を書かない。数値は前提（成約率など）を明示した試算として出す
- アフィリエイト・PR投稿は「PR」「広告」を明記（ステマ規制）
- 情報商材の誇大広告・ネズミ講的な紹介制度・規約違反の手法は提案しない
