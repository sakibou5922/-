# /x-dm — DMの仕分けと文面

## 1. 仕分け
| 種類 | 見分け方 | 対応 |
|---|---|---|
| 制作の相談 | 作りたいもの・困りごとが書いてある | 下の「相談への返事」 |
| 雑談・応援 | 感想だけ | 短くお礼。無理に営業しない |
| 怪しい話 | 「簡単に稼げる」「先にお金を」「外部アプリへ」「個人情報を」 | 返さない。リンクは開かない |
| 営業・勧誘 | 他社サービスの売り込み | 興味がなければ返さなくてよい |

## 2. 相談への返事（最初の1通）
構成：お礼 → 内容の確認（質問は最大3つ）→ 次の一歩（無料でできる範囲の提示）
- 聞くこと：何を作りたいか・いつまでに・予算の目安・今あるサイトのURL
- この時点で金額を確定させない。目安を聞かれたら幅で答える（料金の目安は対象アカウントのファイルの「収益化」欄にあるものだけ使う）

## 3. 追いメッセージ（返事がないとき）
- 2通目：3〜4日後。短く、相手が返しやすい選択肢を1つ（「急ぎでなければまた声かけてください」）
- 3通目：1〜2週間後。これで最後。無理に追わない
- それ以上は送らない

## 守ること
- 一斉送信・同じ文面のコピペ連投・自動送信はしない（スパム判定・凍結の原因）
- お金のやり取りは契約内容をメッセージで残してから。前払いを求める相手・外部アプリに誘導する相手は警戒する
- 相手の個人情報や会社名を、許可なく投稿に使わない
- 各文面を `python3 x/scripts/x_count.py` で数える（DMに文字数制限はほぼないが、長すぎると読まれない）
