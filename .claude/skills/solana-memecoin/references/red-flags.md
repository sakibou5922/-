# 危険サインの意味(ユーザーに説明するとき用)

| 項目 | 何が危ないか | 重さ |
|---|---|---|
| ミント権限が残っている | 開発者がいつでもトークンを追加発行できる。大量発行して売られると価格はほぼゼロになる | 🔴 |
| フリーズ権限が残っている | 開発者があなたのトークンを凍結し、売れなくできる(ハニーポットの一種) | 🔴 |
| 送金手数料(税)が高い | 売買のたびに一定割合を取られる。Token-2022 の機能で仕込まれる | 🔴(2%超) |
| LP が未ロック/未バーン | 開発者がプールの流動性を引き抜ける(典型的なラグプル)。pump.fun からの移行組は通常バーン済み | 🔴 |
| 流動性が薄い | 少し売るだけで価格が大きく下がり、思った値段で売れない | 🟡 |
| 上位10ホルダーの集中 | 少数のウォレットが売るだけで暴落する。プールやロッカーは計算から除外済み | 🟡/🔴 |
| 最大ホルダーの比率が高い | 一人の売りで崩れる | 🟡/🔴 |
| インサイダー保有 | RugCheck が関係者と判定したウォレットの合計。開発者の身内による買い占め | 🔴 |
| インサイダー網(バンドル) | 資金のつながったウォレット群が見つかった。発行直後に複数のウォレットでまとめ買いする「バンドル」の典型 | 🟡 |
| 開発者の保有率が高い | 開発者がまとめて売る(ダンプ)余地が大きい | 🟡 |
| ホルダー数が少ない | 実際に買っている人が少なく、出来高が見せかけの可能性 | 🟡 |
| 開発者の過去発行が多い | 使い捨てのコインを量産している可能性。dev.py で過去作の結末を確認 | 🟡 |
| メタデータ変更可 | 名前やロゴを後から変えられる(偽装・なりすましに使われる) | 🟡 |
| 急騰後 | 24時間で10倍以上。既に上がりきっていて、高値掴みになりやすい | 🟡 |
| 売り優勢 | 売り件数が買いの1.5倍以上。早く入った人が抜けている途中の可能性 | 🟡 |
| 誕生直後 | 1時間未満。ホルダー分布がまだ固まっておらず、判定がぶれやすい | 🟡 |
| SNSなし | X や Telegram がない。コミュニティがなく、続かないことが多い | 🟡 |
| ラグ済み/BAN | RugCheck が「既に抜かれた」と判定、または pump.fun が BAN | 🔴 |

## チェックできないこと(必ず自分の目で確認)
- X や Telegram のフォロワーが本物かどうか(買ったフォロワーやボットの可能性)
- KOL が有料で宣伝しているかどうか
- 開発者が別のウォレットに資金を移しているかどうか(完全な追跡には有料ツールが必要)
- 出来高のうち自作自演(ウォッシュトレード)の割合

## pump.fun の基本
- 新しいコインはまず「ボンディングカーブ」で売買される。買われるほど価格が上がる仕組みで、この間は LP の心配がない。
- カーブの残りが売り切れる(時価総額でおよそ数万ドル)と「graduate」となり、PumpSwap などの通常の取引所プールに移る。
- graduate 直前は注目が集まりやすい一方、graduate した瞬間に早く入った人が売り抜けることも多い。
