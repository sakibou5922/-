# /x-comment — 他人のポストへのリプ・引用

## 手順
1. `x/account.md` から対象アカウントのファイルを読み、口調・キャラ・書かないことを確認する。
2. URL があれば、X公式の埋め込み用API（`https://publish.x.com/oembed?url=<URL>`）で本文を取る。画像はポストページの `og:image` から取得して目で確認する。ログインが要る取得方法・非公開APIは使わない。
3. **絡むかどうかを先に判定**し、理由を一言添える：
   - 絡まない：政治・宗教・特定の個人や会社への批判・炎上中・事実確認できない告発・相手が個人的な悩みを打ち明けているだけ
   - 絡む：仕事のあるある・職場の話・AI・エンジニアのお金・節約など、キャラの話題につながるもの
   - 鮮度：投稿から1〜2時間以内・返信50件未満が理想。古いものは「自分のフォロワー向けの引用」に回す
4. **リプにするか引用にするか**を決める：
   - リプ：相手の読者に見つけてもらう（フォロー獲得）。タイムラインの投稿数を増やさない
   - 引用：自分のフォロワーに見せる。自分の投稿として数える（インプ収益の対象）
5. 3案出す：①相手に乗って自虐で落とす ②自分の体験を1つ足す ③短い共感＋問い
   - 相手を否定しない・揚げ足を取らない・宣伝やリンクを入れない
   - 「すごい」「勉強になる」だけの中身のない返しは出さない
6. 各案を `python3 x/scripts/x_count.py "本文"` で数える。

## 出力
- 判定（絡む / 絡まない）とその理由
- リプ or 引用の推奨
- 3案（文字数つき）とおすすめ1つ
