# /x-viral — 伸びている投稿のスワイプファイル化

## 前提
この環境からは x.com を直接読めないことが多い。その場合はユーザーに次のどちらかを貼ってもらう：
- 参考アカウントの投稿（本文＋表示回数 or いいね数）を各アカウント10件程度
- 伸びた投稿のスクショ（表示回数・いいね・RP・返信・ブックマークが見えるもの）

WebSearch で拾える範囲（まとめ記事など）は補助に使ってよいが、数値は貼られたものを優先する。

## 手順
1. `x/account.md` で自分のニッチと参考アカウントを確認する。
2. アカウントごとに、貼られた投稿の指標（表示回数があれば表示回数、なければいいね数）の **中央値** を出す。
3. 各投稿の **倍率 = その投稿の値 ÷ そのアカウントの中央値** を計算する。フォロワー数の大小に左右されず「そのアカウントにしては異常に伸びた投稿」が分かる。計算は Python で行い、式を見せる。
4. 倍率の高い順にランキング（3倍以上を「当たり」とする）。
5. 上位投稿をそれぞれ分解する：
   - **フック**: `x/hooks.md` の21種のどれか（複合なら併記）と、1行目の文字数
   - **構造**: 例「結論→理由3つ→締めの問い」「ストーリー→学び」
   - **形式**: 単発 / スレッド / 長文 / 画像 / 図解 / 動画 / 引用
   - **感情トリガー**: 共感・驚き・不安・憧れ・怒り など
   - **自分用に転用するなら**: 中身は自分の体験に置き換えた1行目案（丸パクリ禁止）
6. `x/swipe/YYYY-MM-DD-<ニッチ>.md` に表と分解を保存する。既存ファイルがあれば「よく当たる型」の集計を更新する。

## 出力
- 倍率ランキング表（投稿の要約 / アカウント / 値 / 中央値 / 倍率）
- 上位の分解
- 「今週試すべき型 TOP3」
