# /x-audit — 自分のデータの振り返り

## データの受け取り
- 推奨：X Premium のアナリティクス（x.com/i/account_analytics）から投稿データをCSVで書き出し、`x/analytics/` に置いてもらう
- CSVがなければ、投稿ごとの「本文の冒頭・表示回数・いいね・返信・RP・ブックマーク・プロフィールへのアクセス・フォロー増」を貼ってもらう（スクショ可）
- 受け取った数値は `x/analytics/YYYY-MM-DD.md` か `.csv` で保存する

## 分析（Pythonで計算し、使った式を見せる）
1. 期間内の **中央値** を出し、各投稿の倍率（値 ÷ 中央値）でランキング
2. エンゲージメント率 =（いいね+返信+RP+ブックマーク）÷ 表示回数
3. 各投稿を `x/hooks.md` の型・形式（単発/スレッド/長文/画像）・投稿時間帯・目的（集める/信頼/売る）でタグ付けし、タグ別の中央値倍率を比較
4. 収益に近い指標を重視する：プロフィールアクセス・フォロー増・リンククリック・LINE登録/売上（分かれば）
5. 件数が少ない（各タグ5件未満）ときは「傾向の可能性」と書き、断定しない

## 出力
- 当たり TOP5 / 外れ WORST3 と、その理由の仮説
- 効いている型・時間帯・形式
- 来週やめること1つ・増やすこと2つ・試すこと1つ
- 対象アカウントのファイル（`x/account.md` の一覧から選ぶ）の「実績ログ」に日付つきで要点を3行追記する
- `/x-plan` に引き継ぐ一言
