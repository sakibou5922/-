# /x-repurpose — 長い素材を1週間分に分ける

## 手順
1. `x/account.md` から対象アカウントのファイル、`x/hooks.md`、`x/playbook.md` を読む。
2. 素材から「1ポストで言える小さな話」を7つ抜き出す。素材にない事実は足さない。
3. 7つそれぞれに、違うフック型を割り当てる（同じ型を連続させない）。おすすめの組み合わせ：数字 / あるある / 比較 / 質問 / 失敗告白 / 結論先出し / 好奇心ギャップ
4. 7本の単発ポストを書く。重い話と笑える話を交互に並べる。
5. 素材の流れを残したスレッドを1本作る（5〜8本、`/x-thread` の型）。
6. すべて `python3 x/scripts/x_count.py -f <ファイル> --split` で検証する。
7. `/x-human` の観点で仕上げる。

## 出力
- `x/drafts/<ハンドル>/YYYY-MM-DD-repurpose.md` に、7本（`---` 区切り）＋スレッド1本を保存
- 出す順番の提案（1日1本、元の投稿と同じ週に同じ話を連投しない）

## 守ること
- 他人の投稿・記事・動画が素材のときは、要約や転載にしない。本人の意見・体験を入れたオリジナルにする（転載はインプ収益の対象外）
- 伸びた投稿の言い換えは、1〜2週間あけてから
